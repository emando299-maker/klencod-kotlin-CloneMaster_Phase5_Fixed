# CloneMaster Phase 5 — محرك تجريبي لتعديل Package Name

## ما الجديد؟
- يظل استخراج APK وفحصه وتصديره موجودًا.
- أضفنا زر **إنشاء APK معدل وتوقيعه** بعد اختيار ملف APK.
- المحرك يحاول تعديل قيم اسم الحزمة داخل `AndroidManifest.xml` الثنائي، ثم يزيل ملفات التوقيع القديمة ويعيد توقيع الملف بمفتاح محلي مؤقت.
- بعد نجاح العملية يظهر زر تصدير APK الناتج.

## طريقة التجربة على Kleancode
1. افتح المشروع كاملًا من ملف ZIP.
2. اعمل Sync/Build وانتظر تنزيل الاعتماديات الجديدة.
3. افتح CloneMaster، واضغط «اختيار APK لفحصه» واختر APK واحدًا (ليس split APK).
4. أدخل Package Name جديدًا مثل `com.example.game.clone`.
5. اضغط «إنشاء APK معدل وتوقيعه» وانتظر النتيجة.
6. إذا نجحت العملية، صدّر الملف إلى التنزيلات. سيطلب Android تأكيدًا منك عند تثبيته.

## حدود مهمة جدًا
- هذه نسخة تجريبية؛ لم يتم اختبار البناء على Kleancode أو جهاز Android في بيئة التطوير هذه.
- التعديل يغيّر Manifest فقط، ولا يغيّر اسم العرض أو الأيقونة حتى الآن.
- بعض التطبيقات تحتوي اسم الحزمة في ملفات DEX أو موارد أخرى أو تستخدم تحققًا من التوقيع/Play Integrity؛ قد لا تعمل بعد التعديل.
- ملفات split APK / App Bundle غير مدعومة؛ استخراج `base.apk` وحده لا يكفي لهذه التطبيقات.
- التوقيع الجديد مختلف عن توقيع التطبيق الأصلي، لذلك لا يمكن تثبيته كتحديث فوق التطبيق الأصلي؛ استخدم Package Name مختلفًا.
- المحرك لا يتجاوز حماية التطبيقات ولا يضمن استنساخ أي تطبيق.
- مفتاح التوقيع في هذه المرحلة مؤقت ويتجدد مع كل عملية؛ لا تستخدم هذه النسخة لتحديث نسخ معدّلة سابقة.

## المكتبات الجديدة
- `com.android.tools.build:apksig:8.7.3` لإعادة التوقيع.
- `org.bouncycastle:bcpkix-jdk18on:1.80` لإنشاء شهادة توقيع محلية.
